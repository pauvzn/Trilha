🧭 TRILHA: Tu Odisea de Productividad
Trilha (del portugués: Sendero) es una aplicación web de gestión de metas diseñada bajo mecánicas de RPG (Juego de Rol). Transforma la disciplina diaria en una aventura épica donde cada tarea completada otorga XP y te permite subir de nivel a tu personaje.

Características Principales:
Forja tu Héroe: Elige entre clases (Guerrero, Mago o Pícaro) con avatares dinámicos que evolucionan contigo.

Misiones Multinivel: Gestiona objetivos desde misiones diarias rápidas hasta grandes gestas anuales con seguimiento de progreso en tiempo real.

Sistema de Rachas (Streaks): Mantén el fuego sagrado activado; si fallas un día, la racha se reinicia, desafiando tu constancia.

El Oráculo: Un sistema inteligente de mensajes motivacionales que te guía según tu progreso.

Tecnologías: Python (Flask), SQLAlchemy, Jinja2 y DiceBear API.
